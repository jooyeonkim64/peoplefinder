# People Finder

동료들의 경험·강점·관심사를 키워드로 검색해, 필요한 사람을 찾고 질문을 주고받는 내부 네트워크 서비스예요.
첫 사용자는 신입 회계사(입사 동기)이고, 바닐라 HTML/JS와 Node.js 기본 모듈만으로 만들었어요.

## 실행 방법

Node.js 18 이상이 필요해요. 설치할 패키지는 없어요.

```bash
npm start
```

브라우저에서 http://localhost:3000 을 열면 돼요. 다른 포트를 쓰려면 `PORT=4000 npm start`.

## 저장 방식

| 무엇을 | 어디에 |
|---|---|
| 샘플 동료 32명 | `data/sample-data.json` (서버를 켤 때 자동으로 저장소에 반영) |
| 가입자, 프로필, 메시지, 피드백, 새로 등록된 키워드 | `storage/db.json` (파일 기반 DB) |

- 서버(`npm start`)로 열면 모든 내용이 `storage/db.json`에 저장되어, 다른 사람이 가입하거나 메시지를 보내면 서로에게 보여요.
- 비밀번호는 scrypt로 해시해서 저장하고, `storage/` 폴더는 웹에 공개하지 않아요.
- 저장소를 처음 상태(샘플 동료만 있는 상태)로 되돌리려면 `npm run reset`.
- 샘플 동료를 고치려면 `data/sample-data.json`을 수정하고 서버를 다시 켜면 돼요. (매너지수와 받은 피드백은 유지돼요.)

서버 없이 정적 호스팅(Vercel, Cloudflare Pages, GitHub Pages)에 올리면 같은 화면이 '보여주기 모드'로 동작해요.
이때는 가입 정보와 메시지가 각자의 브라우저에만 저장돼서 다른 사람과 공유되지 않아요.

## 시연 순서

1. 회원가입 → 프로필 등록(업무·관심사 키워드, 연락 가능 상태)
2. 홈에서 키워드 검색 → 검색 결과에서 프로필 보기
3. 질문 보내기 → 메시지에서 답장 확인
4. 답장을 받으면 피드백 남기기 → 상대방 매너지수가 올라감

두 사람의 대화를 보려면 브라우저 창 두 개(일반 창 + 시크릿 창)로 각각 가입해 보세요.
샘플 동료에게 질문하면 연락 상태에 따라 몇 초 뒤 자동으로 답장이 와요.

## 폴더 구조

```
index.html               첫 화면 (화면 전체)
core.js                  데이터 처리 로직 (서버·브라우저 공용)
data/sample-data.json    샘플 동료 데이터
server.js                서버 (화면 제공 + /api + 파일 저장)
storage/db.json          저장소 파일
scripts/reset.js         저장소 초기화
```
